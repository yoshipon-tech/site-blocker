# Product Overview

site-blocker は、指定したサイトを開こうとするとブロック画面へリダイレクトする Chrome 拡張。自分で決めたサイト（例: x.com）に無意識にアクセスしてしまうのを止めたい個人向け。

## Core Capabilities

- **ページ読み込み前にブロックする**: `declarativeNetRequest` の redirect ルールで、ページが表示される前に止める
- **ブロック画面を表示する**: 開こうとした元URLを表示し、何が止められたかをユーザーに伝える
- **ブロックリストを実行時に変えられる**: dynamic ルールで管理し、拡張の再ビルドなしに書き換えられる構造にする

## Target Use Cases

- 集中したい時間に、SNS などへのアクセスを機械的に止める
- 開発者モードで読み込み、自分用のブロックリストで使う（第一段階）

## Value Proposition

- **拡張は「止める」、Web は「見せる」**: 役割を分けるので、ブロック画面の変更はデプロイだけで反映でき、拡張の更新やストア審査を待たなくてよい
- **閲覧先を外部に残さない**: 元URLはフラグメント（`#` 以降）で渡すため、ホスティング側のアクセスログに残らない

## Roadmap Direction

- 第一段階: コードに書いたブロックリストを登録し、GitHub Pages のブロック画面に元URLを表示する
- 次段階以降: ブロックリスト編集UI、時間帯・曜日でのブロック、一時解除（「5分だけ開く」）、Chrome ウェブストア公開
