# 見本

実装の完成形。新しい画面を作るときは、まず近いものを見て、余白の取り方と要素の少なさを揃える。
寸法や色はここから目測せず、`../tokens.css` の変数を使う。

| ファイル | 画面 |
| --- | --- |
| `block-light.jpg` | ブロック中（1280×800、ライト）。太陽は残り時間ぶんだけ昇った位置にある |
| `block-dark.jpg` | ブロック中（ダーク）。夜ではなく夜明け前を表す |
| `block-mobile.jpg` | ブロック中（390×844）。見出しと数字を一段落とす |
| `block-done.jpg` | 解除後。太陽が昇りきり、数字が1行の文に変わる |
| `popup-light.jpg` | ポップアップ（360×480）。風景は持たず、リストが主役 |
| `popup-dark.jpg` | ポップアップ（ダーク） |
| `popup-empty.jpg` | ポップアップ（未登録）。行を出さず2行で説明する |
