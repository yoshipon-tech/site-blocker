# Button

主要な操作は塗りつぶしのピル、副次的な操作は輪郭のピル、リスト内の操作は控えめな小ボタンの3種類だけ。

- **Primary** — `ink` の塗りに `sky-top` の文字。1画面に1つまで。ブロック画面では「前のページに戻る」、解除後は「サイトを開く」が該当する。
- **Ghost** — `ink` の輪郭のみ。Primary と並べるときの2番手に使う。
- **Quiet** — `hairline` の細い輪郭に `ink-muted` の文字。リストの行内に置く破壊的操作（削除）用。行の可読性を落とさないために小さく保つが、高さは 32px 以上にする。

角丸は必ず `radius-pill`。太陽と同じ円の言語を保つための決まりで、`radius-md` のボタンは作らない。Primary と Ghost の高さは 48px 以上（`min-height`）。アイコンだけのボタンを作る場合は `aria-label` を必ず添える。

消す・解除するなど取り消せない操作でも赤は使わない。このシステムに警告色はなく、強さは色ではなく階層（Primary / Ghost / Quiet）で表す。
