# SiteRow

登録済みのブロック対象を1件表す行。ドメイン名を左、削除ボタンを右に置き、行の下だけに `hairline` の区切り線を引く。

ドメイン名は `body`（15px）を少し太らせた 500。等幅にはしない。長いドメインは折り返さず省略せず、そのまま表示する。1行に収まらない長さは稀で、省略するとどのサイトか分からなくなるため。

カードにしない。背景・影・囲み枠を持たせると、数件のリストでも画面が重くなる。区切りは下線1本だけ。

削除ボタンは Quiet（`Button` 参照）。確認ダイアログは出さず、押せばすぐ消える前提にする。誤って消しても入力欄から再登録できる程度の操作なので、確認の手数のほうが高くつく。ボタンには `aria-label` でどのサイトを消すのかを添える。

リストの上には `overline` で件数（「登録中（4件）」）を置く。1件もないときは行を出さず、`body` と `small` の2行で空の状態を説明する。
