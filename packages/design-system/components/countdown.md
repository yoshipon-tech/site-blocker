# Countdown

解除までの残り時間。`ink-muted` の説明1行と、`countdown`（76px / 300）の数字の2段組。

`font-variant-numeric: tabular-nums` を必ず添える。1秒ごとに数字が入れ替わるため、字幅が揃っていないと数字が横に揺れる。

太さは 300。見出しの 900 と対にすることで、見出しが語りかけ、時間は静かに流れるという関係を作っている。ここを太くすると「あと何分も待たされる」という圧になる。

表記は残り1時間未満なら `24:13`、1時間以上なら `1:24:13`。先頭のゼロは落とす（`04:13` ではなく `4:13`）。

残り時間が尽きたら、数字を 0 のまま置かずに「集中タイムは終わりました」の1行に差し替える。時間の表示は待っている間だけのもの。

無期限ブロックのときはこの要素ごと出さない。終わりのない数字は示さない。
