# SiteField

ブロックするサイトを1件追加するための、ラベル・入力欄・追加ボタンの組。ポップアップの上部に置く唯一の入力要素。

ラベルは `overline`（12px / 700 / 字間 0.08em）を `ink-muted` で。`placeholder` だけでラベルを省略しない。入力中にプレースホルダは消えるため、何を入れる欄なのかが分からなくなる。`for` と `id` は必ず対応させる。

入力欄は `field` の塗りに `hairline` の枠、角丸は `radius-md`。このシステムで角丸の四角を使うのはこの入力欄だけで、他はすべてピルか直角。高さは 44px 以上。

プレースホルダは入力形式の例（`youtube.com または URL`）にする。ドメインだけでも URL 丸ごとでも受け付ける想定なので、どちらでもよいことが読み取れる文にする。

エラーは枠色を変えて表すのではなく、入力欄の下に `small` / `ink-muted` で1行添える。このシステムには警告色がない。
