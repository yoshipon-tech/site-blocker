# Horizon

このシステムの背景そのもの。空のグラデーション、地面の帯、そして太陽の3つで、すべての画面の下敷きになる。

空は `sky-top` から `sky-bottom` への縦方向のグラデーション。角度をつけたり、色を足して3色にしたりしない。

地面は `ground` の無地の帯で、画面下端に固定する。広い画面では 144px、ポップアップでは 56px。文字やボタンは絶対に載せない。読ませる場所ではなく、地平線を成立させるためだけの面。

太陽は `sun` の正円1つ。`sun-glow` の `box-shadow` で外に光を広げる。ブロック画面では残り時間に応じて位置が上がり、解除時刻にちょうど昇りきる。つまり太陽の高さは進捗バーの代わりであり、装飾ではない。進捗を持たない画面（ポップアップ）では、地平線のすぐ上に半分だけ覗かせて固定する。

太陽を2つ置かない。色を変えない（朝焼けの濃淡は `sun` 1色で足りる）。沈む向きのアニメーションも作らない。昇るという向きだけがこのシステムの意味を担っている。

ダークテーマは夜のブロック画面ではなく、夜明け前を表す。`sky-top` は紺、`sky-bottom` は紫紺に寄り、太陽の色と光量だけが昼夜で変わらない。
