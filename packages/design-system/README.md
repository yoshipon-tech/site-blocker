# Dawn

Chrome 拡張のサイトブロッカーのためのデザインシステム。ブロック画面とポップアップが同じ世界を共有するための、色・文字・部品の決めごとをまとめている。

## 考え方

**待つ時間を、朝が来るまでの時間として見せる。** この拡張が表示するのは「アクセスを禁止された画面」だが、そう見せない。空と地平線と太陽を描き、残り時間に応じて太陽が昇る。使う人は時間切れを待っているのではなく、朝を待っている。禁止の記号（赤、×印、錠前、警告枠）をこのシステムは1つも持たない。

**画面の主役は1つだけ。** ブロック画面なら見出しと太陽、ポップアップなら入力欄とリスト。情報を足したくなったら、足す前にどれを消すかを決める。

**色で叱らない。** 操作の強さは色ではなく階層で表す（`Button` 参照）。削除ボタンも赤くしない。

## 色

`sky-top` から `sky-bottom` への縦グラデーションがすべての画面の地。その上に `ink` の文字、`ink-muted` の補足、`ground` の帯、`sun` の円が載る。使う色はこれで全部で、新しい色を足さずに済むように階層を作ってある。

Light は夜明け、Dark は夜明け前。OS の設定（`prefers-color-scheme`）に従って切り替える。どちらのテーマでも太陽の色 `sun` は変わらない。

文字色の組み合わせは `ink` / `ink-muted` と空の2色の間で 5.3:1 以上を確保している。`ink-muted` より薄い文字色を作らない。

## 文字

Zen Kaku Gothic New 1書体。見出しは 900、残り時間は 300 と、同じ書体の両端を使って対比を作る。中間の太さ（500）はリストのドメイン名だけ。

Google Fonts から読み込む前提だが、拡張機能では同梱フォントに差し替えてもよい。フォールバックは Hiragino Sans / Noto Sans JP。

## 形

角丸はピル（`radius-pill`）が基本。ボタンはすべてピルで、太陽の円と同じ言語を保つ。角丸の四角（`radius-md`）は入力欄にだけ使う。影はグラデーションの地の上で濁るので、太陽の `sun-glow` を除いて使わない。境界線は `hairline` 1種類のみ。

## 余白

4の倍数。要素のまとまりの中は `space-1` 〜 `space-3`、まとまり同士は `space-5` 〜 `space-10`、画面の外周は `space-6`（ポップアップ）か `space-16`（ブロック画面）。

## アイコン

今のところ1つも使っていない。必要になったら線画（stroke）の単色にして `ink-muted` を基本とし、絵文字は使わない。太陽だけは図形であってアイコンではないので、他の円形の図案を増やさない。

## 使う場所

- ブロック画面（リダイレクト先の全画面）— 広い幅と狭い幅の2通り
- 拡張機能のポップアップ（360×520）— サイトの追加と一覧

## 地平線を置く場所

地平線（空のグラデーション・地面の帯・太陽）は、**残り時間を持つ画面にだけ**置く。太陽の高さは残り時間の進捗そのものなので、進捗のない画面に持ち込むと意味を失った大きな図形が残るだけになる。ポップアップや設定画面は単色の `sky-top` を地にして、`sun` は見出し横の小さな印としてだけ使う。
