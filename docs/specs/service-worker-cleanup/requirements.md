# 要件: service-worker-cleanup

## 目的

一度ログインしたことがあるサイト（x.com など）は、ページの読み込みをサイト自身の service worker が受け持つので、ブロックリストに入れても開けてしまう（#30）。
ブロック対象のサイトに登録された service worker を拡張が取り除き、以前に開いたことがあるサイトでもブロック画面に移るようにする。

## 要件

### 1. ブロックが効くようにする

- **1.1** ブロックリストのサイトに service worker が登録された状態でブラウザを起動したとき、システムはその後に開いたそのサイトをブロック画面へ遷移させなければならない
- **1.2** service worker が登録済みのサイトをブロックリストに足したとき、システムはその後に開いたそのサイトをブロック画面へ遷移させなければならない
- **1.3** ブロックリストのサイトに service worker が登録された状態で拡張をインストール・更新・再読み込みしたとき、システムはその後に開いたそのサイトをブロック画面へ遷移させなければならない（`redirect-rules` の版から更新した利用者を含む）
- **1.4** 1.1〜1.3 で取り除く対象は、ブロックリストの各サイトの本体と、その `www.`・`m.`・`mobile.` のサブドメインでなければならない（U1。例: `youtube.com` なら `www.youtube.com` と `m.youtube.com` も）
- **1.5** 1.4 で取り除いたサイトを開いたとき、システムはブロック対象のページの中身を表示せずにブロック画面へ遷移させなければならない
- **1.6** ブロックリストのサイトに残っていた service worker（1.4 に含まれないサブドメインのものなど）がページを表示したとき、システムはそのページをブロック画面へ遷移させ、そのサブドメインの service worker を取り除かなければならない。以後そのサブドメインを開いたときは 1.5 と同じく中身を表示してはならない（U2。中身が一瞬見えるのは、サブドメインごとに最初の1回だけ）

### 2. ほかのデータに触れない

- **2.1** service worker を取り除くとき、システムはそのサイトの Cookie を消してはならない（ブロックリストから外したあとも、ログインしたまま開ける）
- **2.2** システムは、ブロックリストにないサイトの service worker・Cookie・保存データを消してはならない
- **2.3** ブロックリストのサイトに service worker が登録されていないとき、システムは 1.x の操作でエラーを出してはならず、ブロックの状態を変えてはならない

### 3. 権限

- **3.1** システムは、インストール時に利用者に表示される権限の説明を `blocklist-ui` から変えてはならない

### 4. 回帰

- **4.1** 1.1〜1.6・2.1・2.2 は、実装を壊したときに失敗する自動テストで確認できなければならない。ただし実在のサイトの service worker でしか再現できないものに限り、目視とする
- **4.2** 4.1 の自動テストは、ブロックリストのサイトや公開中のブロック画面へ実際に接続せずに通らなければならない

## 範囲外

- ブロックする時間帯が始まったときに取り除くこと — `schedule-blocking`（#12）で、この機能の処理を呼ぶ
- service worker 以外の理由でブロックをすり抜けるサイトへの対策 — 見つかったら別の issue にする（#30 の「採らなかった案」）
- ブロックリストから外したサイトの service worker を戻すこと — サイトを開き直せばサイト自身が登録し直す
- ブロック中のサイトへの通知（プッシュ通知）の扱い — service worker を取り除くとそのサイトの通知も届かなくなるが、ブロック中は開かせないので受け入れる

## 未決事項

なし（以下は決定済み）

| 論点 | 決め方 |
| ---- | ------ |
| U1: サブドメインの service worker をどこまで取り除くか（取り除く API はオリジンを完全一致で指定する） | **決定: 先に消す＋開いたら消す。** 本体と `www.`・`m.`・`mobile.` を先に取り除き（1.4）、それ以外は開いた時点で気づいて取り除く（1.6） |
| U2: 残っていた service worker のページが、最初の1回だけ一瞬見えることを許すか | **決定: 許す**（1.6）。サブドメインごとに最初の1回だけ |
