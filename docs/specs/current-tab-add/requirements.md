# 要件: current-tab-add

## 目的

ブロックしたいサイトは「いま開いていて、つい見てしまったサイト」であることが多い。しかし今のポップアップでは、ドメインを入力しないと追加できない。
ポップアップに今開いているページのサイトを表示し、1回の操作で追加できるようにする。見た目は `mock-addable.png`（追加できる状態）に従う。

## 要件

### 1. 今開いているページの表示

- **1.1** 利用者がポップアップを開いたとき、システムはポップアップを開いたウィンドウで選択中のタブのページについて、サイトを入力欄より上に表示しなければならない
- **1.2** 1.1 のサイトは、`blocklist-ui` の入力と同じ規則（2.4 小文字化・2.5 ホスト名の取り出し・2.6 `www.` を外す）で作ったドメインでなければならない（`https://www.note.com/foo` → `note.com`）
- **1.3** 1.1 のページが追加できるとき、システムはそのサイトの横に追加の操作を表示しなければならない
- **1.4** 1.1 のサイトが既にブロックリストにある（そのサイトかサブドメイン）とき、システムはカードを表示し、そのサイトが登録済みであることを表示し、追加の操作を表示してはならない
- **1.5** 1.1 のページが追加できない（`http`・`https` 以外のページ、ブロック画面自体）とき、システムはカードを表示し、そのページは追加できないことを表示し、追加の操作を表示してはならない

### 2. 今開いているページの追加

- **2.1** 利用者が 1.3 の追加の操作をしたとき、システムは入力欄に入力して追加したとき（`blocklist-ui` 2.1〜2.3・2.8・2.9）と同じ結果にしなければならない
- **2.2** 2.1 で保存したとき、システムは 1.1 の表示を、そのサイトが既にブロックリストにあるときの表示（U1）に変えなければならない
- **2.3** 2.1 で保存したとき、システムは今開いているタブを再読み込みしたりブロック画面へ移したりしてはならない（次に開いたときからブロックされる）

### 3. 既存の操作

- **3.1** 入力欄からの追加・一覧・削除（`blocklist-ui` 1.x・2.x・3.x）は、この機能の前と同じに動かなければならない

### 4. 権限

- **4.1** システムは、インストール時に利用者に表示される権限の説明を `service-worker-cleanup` から変えてはならない
- **4.2** システムは、ポップアップを開いていないときに、利用者が開いているページの URL を読んではならない

### 5. 回帰

- **5.1** 1.2・1.4・1.5 のカードの状態の判定と 3.1 は、実装を壊したときに失敗する自動テストで確認できなければならない。カードの表示と追加の操作（1.1・1.3・2.x）は目視で確認する
- **5.2** 5.1 の自動テストは、実在のサイトや公開中のブロック画面へ実際に接続せずに通らなければならない

## 範囲外

- 今開いているページのパス単位の追加（`youtube.com/shorts` だけ） — `blocklist-ui` と同じ理由で、ルールの組み立ての変更が要る
- 右クリックメニューやキーボードショートカットからの追加 — 必要になった時点で別の機能にする
- 今開いているページのサブドメインと親ドメインを選んで追加する操作（`news.yahoo.co.jp` か `yahoo.co.jp` か） — 1.2 の規則どおり、ホスト名から `www.` だけを外したものを出す。親ドメインで止めたいときは入力欄を使う
- ダークテーマなど、モックにない見た目の作り込み — `blocklist-ui` の Dawn の見た目に揃える範囲にとどめる

## 未決事項

なし（以下は決定済み）

| 論点 | 決め方 |
| ---- | ------ |
| U1: 今のページが既にブロックリストにある（そのサイトかサブドメイン）とき、どう見せるか。ブロック中のサイトは開くとブロック画面に移るので、起きるのは主にカードから追加した直後（2.3 でタブを移さない）・追加前から開いていたタブ・権限がなくブロックされていないサイト | **決定: 案A** カードは出したまま「登録済み」と表示し、追加の操作を出さない（1.4） |
| U2: 今のページが追加できないとき、どう見せるか | **決定: カードを出し、追加できないことを表示する**（1.5） |
| U3: 追加ボタンを入力欄の「追加」と見分けるか | **決定: モックどおり**（両方「追加」で、強調の有無で見分ける）。使ってみて紛らわしければ見直す |
