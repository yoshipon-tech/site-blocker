# spec: schedule-blocking — 時間帯・曜日によるブロック

## 範囲

`apps/extension`

## やること

ユーザーが決めた時間帯・曜日のあいだだけ、ブロックリストのサイトをすべてブロックする。`alarms` の利用を検討する。

## 決まっていること

- ブロックする時間帯はユーザーが定義する
- 時間帯はブロックリスト全体に1つ。サイトごとには設定しない（指定した時間帯は、登録したサイトをすべてブロックする）
- 持てる時間帯は1つだけ（複数の時間帯は持たない）
- 時間帯を設定していないときは常にブロックする（今の挙動のまま。更新しても変わらない）
- 時間帯の外であることは、ポップアップなどに表示しない
- 時間帯は「開始・終了の時刻」と「曜日」で表す
- 開始が終了より遅い時刻（例: 22:00〜6:00）なら、日をまたぐ時間帯とみなす
- 曜日は、時間帯が始まった日で数える（「金曜 22:00〜6:00」は金曜 22時から土曜 6時まで）
- 開始と終了に同じ時刻は設定できない
- 終了時刻にだけ 24:00 を選べる。選んだ曜日を終日ブロックするときは 0:00〜24:00 にする（その曜日の 0時から 24時まで）
- 毎日ずっとブロックしたいときは、時間帯を設定しない（未設定なら常にブロック）

ある時刻をブロックするのは、次のどちらかに当てはまるとき。

- 今日が選んだ曜日で、開始時刻を過ぎている（日をまたがない時間帯なら、終了時刻より前でもある。終了が 24:00 ならその日の終わりまで）
- 日をまたぐ時間帯で、昨日が選んだ曜日で、今は終了時刻より前

例: 平日（月〜金）22:00〜6:00

| いつ | ブロック | 理由 |
| ---- | -------- | ---- |
| 月曜 23時 | する | 月曜に始まった時間帯の中 |
| 火曜 5時 | する | 月曜に始まった時間帯の続き |
| 土曜 5時 | する | 金曜に始まった時間帯の続き |
| 月曜 5時 | しない | 前日の日曜は選んでいない |

## 決めること（spec で）

なし（時刻はブラウザのローカル時刻で判定する前提。違えば spec で見直す）

前提: #10 / ブロック画面に解除時刻（時間帯の終わり）を渡すかは [unblock-time](unblock-time.md) で先に決める / 時間帯の変更にパスワードを求めるかは [settings-lock](settings-lock.md) と合わせて決める
